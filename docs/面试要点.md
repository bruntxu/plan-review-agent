# 面试要讲清的点（项目完成后统一学习）

做项目的过程中，把面试可能追问的设计点记在这里。最后集中学习：先看大白话解释，再去看对应的代码。

| # | 问题 | 一句话答案 | 代码位置 |
|---|---|---|---|
| 1 | 为什么编号和一致性检查不用大模型？ | 能用规则查的就用规则：结果每次都一样，0.4 秒、不花钱；大模型只做需要"读懂意思"的判断 | `checks/` 整个目录 |
| 2 | 怎么知道一个表题属于哪套编号？ | 按前缀和编号形式分组（附录A表N / 附表N / 表C-N），每组单独检查是否连续 | `table_numbering.py` 的 `find_captions` |
| 3 | "章号倒退"在抓什么？ | 第 5 章里出现"表 1-2"，几乎都是从第 1 章复制过来忘了改号 | `table_numbering.py` 规则 2 |
| 4 | 四处名单以哪处为准？为什么？ | 以实际章节为准，因为章节是文档里真实存在的内容，目录和列表都是"描述"它的 | `list_consistency.py` |
| 5 | 名称很像但不一样，怎么配对？ | 先配完全相同的，再在剩下的里每次挑全场最像的一对（相似度 ≥ 0.6）。先到先得会配错，案例B v3 就是例子 | `list_consistency.py` 第二轮匹配 |
| 6 | 域没闭合为什么能导致文档"消失"？ | 域由 begin/separate/end 三部分组成，可以跨好几段；删掉后半段，Word 就认为后面所有内容都还在域里 | `field_integrity.py` |
| 8 | 客户文件发给第三方大模型，隐私怎么处理？ | 先脱敏，再加一道发送前的安全网；同一原文永远对应同一占位符，模型仍能判断"是不是同一家公司"；结果回来再换回真名 | `desensitize.py`、`llm.py` |
| 9 | 脱敏是怎么调对的？ | 先"预演"：只生成要发送的内容、不真的发，人工检查。抓出了把"批准""报告"当人名、漏掉公司简称这两个 bug | `scripts/preview_masked.py` |
| 10 | 为什么 T4 要用大模型？ | "本公司主要从事智能配电设备的研发"每个字都没错，只有读懂意思、对照本单位经营范围，才知道说的是别家公司 | `checks/template_residue.py` |
| 11 | 模型乱编段落号怎么办？ | 只接受当前这块里真实存在的段落号，其余丢弃 | `template_residue.py` |
| 12 | 第一版 T4 报了 156 处，怎么降下来的？ | 看误报分类：属地误报是因为地址被脱敏、模型不知道本单位在哪 → 画像加地区；模板章节误报 → 提示词写明不算。同时要求引原话、分高/中把握 | `template_residue.py` 顶部注释 |
| 13 | 补充画像为什么能提高检出？ | 模型只有知道"本单位没有叉车、没有车间"，才敢判定"放下叉脚"是残留。C 方案的真残留从 20 条增加到 38 条 | `docs/进度与结果.md` |
| 14 | 准确率怎么算的？ | 把结果做成标注表，每条标成真残留 / 模板措辞 / 误报，由懂行的人确认；高把握结果里真残留占 63%，误报占 10% | `scripts/make_label_sheet.py` |
| 15 | 表格里怎么知道哪个号码是谁的？ | 一行里只有一个人名时，才把这一行的号码配给他；一行有好几个人名就不配，宁可漏也不乱配 | `consistency.py` 表格部分 |
| 16 | "员工 8 人组成救援队伍"为什么没被当成员工人数？ | 员工人数的规则排除了后面跟"组成"的情况；队伍人数单独抽出来，再跟员工人数比大小 | `consistency.py` R6 |
| 17 | 注入式评测是什么？为什么要做？ | 用真实文档只知道"查出了多少"，不知道"漏了多少"。自己埋已知的错，位置和类型都确切，就能算召回率 | `bench/inject.py` |
| 18 | 规则检查 100% 召回，可信吗？ | 不能全信：错是自己埋的、规则也是自己写的，只说明规则按设计在工作。真实效果要看跟专家意见的对照。我在报告里把这一点写明了 | `docs/进度与结果.md` |
| 19 | 评测发现过什么问题？ | 一是"改员工人数"测不出来，因为全文只出现一次，没东西可比，顺带发现 T5 没读表格；二是读表格后出现"叄/叁"异体字误报 | 同上 |
| 20 | 为什么要规则和模型组合？ | 难题里模型漏掉的主要是数字矛盾，规则正好能补上：模型单独 8/12，合起来 11/12。规则管"对比和计数"，模型管"读懂意思" | 同上 |
| 21 | 怎么省评测的钱？ | 只发送包含埋错段落的那几块，切块方式不变，模型看到的上下文和正常审查一样；每组约 0.07 元 | `template_residue.py` 的 only_indices |
| 22 | 这算 Agent 吗？LangGraph 在这里起什么作用？ | 老实说，它是一张有条件分支的流程图，"制定计划"节点目前是确定性规则，不是大模型自己决定。LangGraph 负责状态合并、按条件跳过大模型节点、逐步汇报进度；以后可以把计划节点换成大模型规划，其他节点不用动 | `agent.py` |
| 23 | 为什么上传后接口立刻返回，而不是等审查完？ | 开了大模型要几十秒，HTTP 请求一直挂着容易超时。所以后台线程去跑，前端拿任务号轮询进度，同时还能显示每一步做了什么 | `api.py` |
| 24 | 演示用什么数据？ | 自己生成的虚构预案，埋了各类真实遇到过的错误。真实客户文件不进仓库、不进镜像 | `make_demo_docx.py`、`.gitignore`、`.dockerignore` |
| 7 | 怎么证明检查有效？ | 跟真实专家意见逐条对照（命中几条、漏了几条、多查出几条），再加上注入式基准（待做） | `docs/进度与结果.md` |
